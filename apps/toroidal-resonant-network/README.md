# Toroidal Resonant Network

A single-file, offline, dependency-free simulation of a closed toroidal circuit compared with a one-way feedforward system.

A healthy circuit sends energy outward into experience, then curves it back through a single unchanging center, at every scale (Microscopic, Interpersonal, Local Fork, Macroscopic). A feedforward system only pushes outward, so small disturbances accumulate as drift. This is an illustrative model of an architecture, not an empirical measurement of any person or group. It does not score, rank, or label people.

Drive folder `04` (Outreach, Simulation & White Papers). Keep this app source-agnostic: do not add fellowship names, treatment or admissions material, or personal details.

## How to run

1. Open `index.html` in any modern browser. No server and no internet are needed.
2. Optional: append `?seed=123` to the file URL to make the particle layout repeatable.
3. Toggle **Toroidal Resonant Circuit** versus **Standard Feedforward AI (Linear Drift)**.
4. Inject a scenario: 3:00 AM Crisis Triage, Director's Chair / Ego Defensiveness, Religious Gatekeeping / Tribal Division, or Daily Gratitude & Two-Minute Pause.
5. Adjust respiration rate and return curvature. The live readout (return ratio, field coherence, edge drift) describes the simulated field only.
6. Open **Open-source reference blueprint** for a short PyTorch module and the JavaScript `ringStep` function this page actually runs.

If the system asks for reduced motion, the page starts paused. Press Resume to animate.
